Product Requirement Document.

### Why OmaZoom? Two reasons

1. OmaZoom was created to compete in the omarchy plugins competition.
2. OmaZoom is a handy idea that was originally inspired by GNOME's own window management. Hyprland is an amazing product that sorts and visualises an individual workspace, but neither it or Omarchy bring a cohesive organization to _workspaces_ (with an s).

### A compact list of features

- Preview each workspace on the side, with a miniature view of each workspace and the tabs open.
- Configure each workspace to allow spawn certain applications.
  - If you want to open chrome - you'll go to the Chrome workspace.
  - If you are in a coding session, you'll work in the coding workspace.
  - Each workspace will come preequiped with the ideal layout: dwindle, scrolling, spotlight.
- Workspaces spawn dynamically when you request to open an app attached to a workspace.
- Opening a workspace will result in all the apps that the workspace being opened.
- As well as workspaces, users can create "personalities" - if they're gaming, coding, or in a meeting their workspace configurations will now be different.
- The plugin will ship with several already built workspaces and users to aid in onboarding.

### The central idea behind each feature

- This allows for quick and visual navigation. With a create button press you know exactly what is open and where it is open.
- Often times in a deep work session you can get so carried away with work that one forgets where a tab or session they were working on; this can be jarring and painful to renter. It shouldn't be this way, you should always know where everything is and be able to switch to it fast.
- If I know I want to code, typically I know exactly which applications and tabs need to be open in order to achieve this. For example, coding: nvim, claude, and github. This should be instant. Furthermore, it should be customisable to the exact work directory.
- Now personalities is where the product begins to go off the deepend. The idea behind it is simple: all this workspace control can feel a bit trapping. Additionally, hobby workspaces are going to look very different than work workspaces or entertainment spaces. (This idea may be scratched).
